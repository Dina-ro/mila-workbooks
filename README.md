# MILA · עמוד נחיתה

עמוד נחיתה לסדרת חוברות השפה MILA לילדים דוברי עברית.

## העלאה ל־GitHub Pages
1. יוצרים מאגר חדש ב־GitHub (למשל `mila`).
2. מעלים את כל התוכן של התיקייה הזו: `index.html`, התיקייה `img` והקובץ `.nojekyll`.
3. ב־Settings › Pages בוחרים: Deploy from a branch › `main` › `/ (root)` ושומרים.
4. אחרי דקה־שתיים העמוד זמין בכתובת `https://<שם-משתמש>.github.io/mila/`.

## עדכונים נפוצים
- **קישורי אמזון:** בתחתית `index.html`, בשורות `asin:"..."` של כל חוברת. חוברת חדשה שעלתה לאמזון: מעתיקים את ה־ASIN מכתובת הדף (`/dp/XXXXXXXXXX`).
- **וואטסאפ:** השורה `const WA = ...`.
